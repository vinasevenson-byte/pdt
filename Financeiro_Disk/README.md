# Financeiro Disk — versão fiel da interface

Este projeto apresenta exatamente os bytes do HTML original (`index.html`), sem componentes substitutos, sem telas recriadas e sem valores inventados.

Com Node.js instalado, execute `npm run test`, depois `npm run dev` (porta padrão 5173). Para usar a porta 5173, no Windows PowerShell: `$env:PORT=5173; npm run dev`; em Linux/macOS: `PORT=5173 npm run dev`.

**Limites:** este é o HTML original servido localmente, não uma migração React/TypeScript, nem conexão validada ao Firebase. Os dados exibidos e operações internas devem ser auditados antes de uso operacional. Não habilita movimentações bancárias.
